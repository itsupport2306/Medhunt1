Install Medhunt Watcher

The watcher is separate from the normal Medhunt recruiter extension. The Medhunt backend must already be installed and running.

  1. Open chrome://extensions or edge://extensions.
  2. Enable Developer mode.
  3. Select Load unpacked.
  4. Select this folder:{{WATCHER_PATH}}
  5. Open Indeed Smart Sourcing and sign in.
  6. On Indeed, enter the search string and location, select Sort by: Most recent, click Find, and wait for candidate cards.
  7. Open Medhunt Watcher, choose the interval, then select Watch current search.

Keep the browser and authorized Indeed session running. The watcher reapplies Most recent before every scheduled comparison.
