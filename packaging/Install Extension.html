Finish installing Medhunt

The local backend is installed and starts automatically when you sign in to Windows.

Chrome

  1. Open chrome://extensions.
  2. Turn on Developer mode in the upper-right corner.
  3. Select Load unpacked.
  4. Select this exact folder:{{EXTENSION_PATH}}
  5. Pin Medhunt, then reload any open Indeed, LinkedIn, Facebook, Vivian, ZipRecruiter, NPI No., NPI Profile, or NYSED tab.

Microsoft Edge

Use edge://extensions, enable Developer mode, and follow the same Load unpacked steps.

Check the backend

Open http://127.0.0.1:8091/health. It should show "status":"ok".

Application data

Application data and logs are managed under:

{{DATA_PATH}}

Contact access and configuration are managed by your Medhunt administrator.

Updates

Run a newer Medhunt-Setup.exe to upgrade. Your local configuration and database are preserved. Then select Reload on the browser's Extensions page.
